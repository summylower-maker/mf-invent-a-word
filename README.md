One invented English word with a one-line definition — *Ghostdraft (n.): a message typed out in full but never sent, left haunting the compose box.* — entered in make.fun's "Invent a Word We Need" bounty. See the bounty page: https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0

## Run it

```sh
python3 main.py
```

`main.py` (Python 3 compatible) does no network access, uses no randomness and no timestamps: it writes the one-line entry deterministically to `/output/entry.txt` (with a `./output` fallback). Running it twice produces byte-identical output.
